## セキュリティ関連ニュース

### 1. Grafana、GitHub Actions の「Pwn Request」脆弱性を突かれ内部リポジトリ5件が流出
**公開日**: 2026-05-16  
**ソース**: The Hacker News / cybersecuritynews.com / grafana.com 公式ブログ

オープンソースの観測プラットフォーム **Grafana** が、**CoinbaseCartel**（ShinyHunters / Scattered Spider / LAPSUS$ の一派とされる脅威グループ）によるサプライチェーン型攻撃を受けたと公式に開示した。

**攻撃手法（"Pwn Request"）:**  
GitHub Actions の `pull_request_target` イベントは、フォークリポジトリからのプルリクエストに対しても親リポジトリの秘密情報（シークレット）へのアクセスを持つワークフローを実行できる。攻撃者はこの仕様を悪用し、以下の手順で侵害を実施した。

1. Grafana の公開リポジトリをフォーク
2. 悪意ある `curl` コマンドをワークフロー YAML に挿入したプルリクエストを作成
3. `pull_request_target` ワークフローが自動実行され、親リポジトリの特権トークンを外部サーバーへ送信
4. 取得したトークンを用いて **プライベートリポジトリ 5件** にアクセス・コードベースをダウンロード
5. 支払いを要求（身代金交渉）

**Grafana の対応:**  
FBI のガイダンスを根拠に身代金支払いを拒否。影響を受けたトークンを即時失効させ、ワークフロー設定を修正。顧客データ・PII の流出はないと発表。

**教訓:**  
Wiz・StepSecurity の分析によると、`pull_request_target` を使用するパブリックリポジトリの多くが同様の構成ミスを抱えている。対策として、フォークからの PR には `pull_request` イベント（シークレットなし）を使用し、信頼済みコードのみに特権を付与するよう設計変更が推奨される。

### 2. [続報] CVE-2026-42897 (Microsoft Exchange XSS) — 永続的パッチを5月延期、緩和策のみ提供
**公開日**: 2026-05-16  
**ソース**: SecurityWeek / Microsoft Community Hub

2026-05-15 に公開された **Exchange Server の反射型 XSS 脆弱性** CVE-2026-42897（CVSS 8.8）について、マイクロソフトは「2026年5月のセキュリティ更新プログラムには Exchange Server の修正は含まれない」と Community Hub ブログで明言し、永続的パッチの提供を延期した。

**現時点の対応策（緩和策 M2.1.x）:**  
- OWA（Outlook Web App）のカレンダー印刷機能およびメール本文インライン画像の一部表示機能を無効化するサーバー側設定変更を適用することで攻撃ベクターを遮断可能。
- 設定手順は [Microsoft Learn](https://learn.microsoft.com) の Exchange サーバー設定ガイドで公開予定。

**影響範囲:**  
Exchange Server 2019 以降のオンプレミス環境。Exchange Online（クラウド版）は対象外。

SecurityWeek の 5月16日付記事は「組織は緩和策を適用した上で、永続的パッチのリリースを待つよう」勧告している。

### 1. [続報] CVE-2026-42897 — 国内 Exchange 運用組織への影響と JPCERT/CC 注意喚起
**公開日**: 2026-05-16〜17  
**ソース**: JPCERT/CC Early Warning / Microsoft Community Hub (日本語版)

上記 CVE-2026-42897 に関し、国内においても金融・製造・公共機関を中心にオンプレミス Exchange Server の利用が継続されており、JPCERT/CC は 5月16日の Early Warning Information にて国内組織向けの注意喚起を実施（参考: 過去の同種 OWA 脆弱性では数週間以内の実証コード公開が確認されている）。

**推奨事項:**  
1. 社内展開 Exchange Server のバージョン確認（2019 CU14 以降）
2. マイクロソフト提供の緩和策スクリプトを速やかに適用
3. OWA アクセスログの異常なリダイレクト・スクリプトインジェクションの有無を監視
4. 永続的パッチ公開後（6月 Patch Tuesday 予定）に速やかに適用

### 2. 能動的サイバー防御法 — 施行準備状況（省令・規則整備フェーズ）
**公開日**: 2026-05-17 (NHK / 日本経済新聞ウェブ)  
**ソース**: NHK Web / 日本経済新聞

2025年末に成立した **能動的サイバー防御法**（サイバー安全保障対策強化法）の施行準備が進んでいる。内閣サイバーセキュリティセンター（NISC）および総務省・経済産業省は、重要インフラ事業者への義務付け範囲と通報フローを定める省令・規則の整備を 2026年夏までに完了させる方針。施行は **2026年10月予定**。

**主要論点:**  
- 政府機関による「先制的アクセス（能動的防御）」の実施要件と司法的統制の仕組み
- 通信の秘密に関する憲法上の制約との調整（令状主義との整合）
- 民間クリティカルインフラへの義務的報告基準（インシデント発生から **72時間以内**）

経済界・法曹界から施行規則の透明性確保と独立した監視機関の設置を求める声明が相次いでいる。
